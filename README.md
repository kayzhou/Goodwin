# Goodwin
一个支持左右分屏、最大化和最小化的原生 macOS 菜单栏工具。无第三方依赖。

## 安装
从 [GitHub Releases](https://github.com/kayzhou/Goodwin/releases) 下载 DMG，打开后把 Goodwin 拖入 Applications，再从「应用程序」启动。当前安装包为本地签名，未经 Apple 公证。系统要求见对应发布页。

## 使用
1. 打开 Goodwin，在菜单栏找深蓝标题栏、银灰边框的彩色双窗口图标。本工具没有主窗口。
2. 点击图标 → **开启辅助功能…**，在系统设置中允许 Goodwin。如果列表里没有，使用 `+` 添加实际运行的 Goodwin.app；未授权时不占用四个方向快捷键；Goodwin 检测到授权后会自动启用。
3. 拖动 Finder 或浏览器窗口的标题栏，让鼠标靠近屏幕左、右或上边缘。无填充的黑白细边框是松手后的范围；不松手拖回中央即可取消。也可以先点击目标窗口，再从 Goodwin 菜单选择布局。

也可直接对当前窗口使用四个全局快捷键：**Control + Option + ←** 左半屏、**Control + Option + →** 右半屏、**Control + Option + ↑** 最大化、**Control + Option + ↓** 最小化到程序坞。用 Goodwin 最小化后，再按 ⌃⌥↑、⌃⌥← 或 ⌃⌥→，会恢复最近一次最小化的窗口并按方向布局。若菜单提示快捷键未注册，请先释放其他软件占用的相同组合，再重启 Goodwin。

“最大化”按屏幕的可用区域计算，不会切换到独立全屏空间。填不满时，按应用实际接受的尺寸在当前可用桌面居中；尺寸固定但可移动的窗口保持原大小居中。左右分屏规则不变，不处理原生全屏窗口。个别应用的最小宽度可能超过半屏。如果出现两个预览，先退出其他吸附工具，并在系统设置的“桌面与程序坞”里关闭与 Goodwin 重叠的拖动平铺选项。本应用不会替你修改系统设置。

## 屏幕标注
全局按 **⌃⌥↩**（Control + Option + 主键盘回车）或从菜单栏选「屏幕标注」，指针变为黑金钢笔，在当前屏幕拖动画玫瑰红笔迹，按住 Shift 拖动画箭头。⌘Z 撤销，Esc 清除并退出。按回车保留标注，继续点按下方窗口；菜单中可继续或清除。也可再按 ⌃⌥↩ 保留标注，再按继续画。标注快捷键无需辅助功能权限。标注只在内存中，不截图。

## 本地构建
在此目录运行 `./build.sh`（需 macOS 和 Xcode Command Line Tools），脚本先运行几何和拖动判定测试，再编译并本地签名。重编译或更换应用位置后可能需重新授权。

## 手动验证
在辅助功能授权后，用 Finder 和浏览器各测试四个方向键，并从程序坞恢复最小化的窗口；确认拖回中央不调整大小、拖选文字不触发吸附。若有外接屏，再验证跨屏拖动后布局落在指针所在的屏幕上。
