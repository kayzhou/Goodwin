# Goodwin · 把窗口排好，把重点圈出来。

左边放资料，右边写稿。轮到你讲时，按一下回车组合键，鼠标就变成钢笔。圈出那一行，再按回车——圈还在，你已经可以点下一页了。

Goodwin 是一个住在 Mac 菜单栏里的窗口与标注工具。认准那枚 Win98 风格的蓝灰双窗口图标就好：没有主窗口，也没有一排挡住内容的画笔按钮。

## 四个方向，安排一扇窗

按住 **Control + Option**（`⌃⌥`），方向键就是窗口的位置。

| `←` 左半屏 | `→` 右半屏 | `↑` 最大化 | `↓` 最小化 |
| :---: | :---: | :---: | :---: |
| 靠左，留出右边 | 靠右，留出左边 | 填满桌面，不切换空间 | 收进程序坞 |

刚收起来，又想对照一眼？用 Goodwin 最小化后，按 `⌃⌥←`、`⌃⌥→` 或 `⌃⌥↑`，刚才那扇窗会回来，直接落在你选的位置。遇到不能铺满的窗口，最大化会按它实际能达到的大小居中。

**喜欢用鼠标？** 拖住标题栏，让指针碰到屏幕左边、右边或顶部。细边框标出松手后的范围；改变主意，拖回来就好。

## 一支钢笔，讲清你指的是哪儿

共享屏幕时，不用再说「右边，再往下一点」。按 **`⌃⌥↩`（Control + Option + 主键盘回车）**，用黑金笔尖直接圈给对方看。墨迹是玫瑰红，落在屏幕上，不改动底下的文档。

| 想做什么 | 怎么做 |
| --- | --- |
| 圈重点、画下划线 | 直接拖动；按住 `Shift` 拖动就是直箭头 |
| 刚才那笔画错了 | `⌘Z` 撤销上一笔 |
| 留着圈，继续点下面的窗口 | `↩` 保留笔迹，让鼠标穿透；再按 `⌃⌥↩` 接着画 |
| 讲完，收笔 | 绘制时按 `Esc` 清除并退出；已保留的笔迹可从菜单里清除 |

不想记快捷键，也可以点菜单栏里的「屏幕标注」。标注只在内存中，不截图，不保存屏幕内容。

## 安装与首次使用

1. 打开 DMG，把 **Goodwin** 拖到 **Applications（应用程序）**，再从那里启动。
2. **只用标注？** 按 `⌃⌥↩` 就能开始，不需要辅助功能权限。
3. **也要管理窗口？** 点菜单栏图标 → **开启辅助功能…**，在系统设置中允许 Goodwin。授权后四个方向键会自动启用。

<details>
<summary>权限、快捷键或窗口尺寸不对？</summary>

- 辅助功能列表里没有 Goodwin：点 `+`，添加「应用程序」里的 `Goodwin.app`。本地签名版本更新或移动后，可能需要重新授权。
- 菜单提示「快捷键未注册」：先释放其他软件占用的相同组合，再重启 Goodwin。
- 拖动时出现两个预览：检查是否同时启用了 macOS 边缘平铺或其他吸附工具。Goodwin 不会替你更改系统设置。
- 某个窗口比半屏宽：应用可能规定了最小宽度。Goodwin 不强制突破尺寸限制，也不调整原生全屏空间中的窗口。

</details>
